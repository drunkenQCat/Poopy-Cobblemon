# Project icons

Square PNG icons for the CurseForge project pages, generated with the built-in OpenAI image generation tool.

- [Poopy Cobblemon](poopy-cobblemon.png): toilet and monster-catching ball.
- [Cobblemon Ext](cobblemon-ext.png): monster-catching ball and code brackets.

These non-code assets use the repository's [CC BY-NC 4.0 asset license](../LICENSE-ASSETS.md).

## Poopy Cobblemon prompt

Use case: logo-brand. Create ONE finished square 1024x1024 PNG icon for the Minecraft NeoForge mod Poopy Cobblemon, for a CurseForge project avatar. No words or letters. Design a playful, very readable chunky pixel-art emblem: a white porcelain toilet viewed in three-quarter isometric view, lid open, with a single iconic red-and-white monster-catching ball perched prominently above the bowl, black horizontal belt and central white button. Keep it cute and clean, no feces, no gross realism, no characters. A tiny cyan sparkle suggests magic. Crisp deliberately stair-stepped pixel edges and large simple pixel clusters, subtle blocky shading, dark ink outlines; premium indie Minecraft item-sprite aesthetic, not a photorealistic render, not smooth vector. Opaque deep midnight navy square background, small teal halo directly behind the object. Palette porcelain white, pale ice blue, coral red, rich teal, near-black navy. One centered large silhouette using about 78 percent of canvas, generous safe margin, no frame, no mockup, no collage, no watermark. Strong contrast, legible as a tiny 64px avatar. This belongs to a matching pair with a Cobblemon extension-library icon that uses the same background, outline weight and red-white ball.

## Cobblemon Ext prompt

Use case: logo-brand. Create ONE finished square 1024x1024 PNG icon for the Minecraft NeoForge library Cobblemon Ext, for a CurseForge project avatar. No words or letters. Design a very readable chunky pixel-art emblem: one large red-and-white monster-catching ball at the center, black horizontal belt and central white button, flanked by bold cyan pixel code angle brackets < and >, conveying an extension API and connection bridge. Two short blocky cyan connector traces link brackets to the ball. No toilet, no characters, no computer monitor. Crisp deliberately stair-stepped pixel edges and large simple pixel clusters, subtle blocky shading, dark ink outlines; premium indie Minecraft item-sprite aesthetic, not photorealistic, not smooth vector. Opaque deep midnight navy square background with a small teal halo immediately behind the emblem. Palette porcelain white, pale ice blue, coral red, rich teal, near-black navy. Single centered compact emblem using about 78 percent of canvas, generous safe margin, no frame, no mockup, no collage, no watermark. Strong contrast, legible as a tiny 64px avatar. It must feel like a companion to the Poopy Cobblemon toilet-and-ball icon, with the same background, outline weight and red-white ball design.
