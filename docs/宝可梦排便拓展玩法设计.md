# 《宝可梦排便》拓展玩法设计提案

> 项目：Poketoilet（PoopSky × Cobblemon 附属）
> 版本：提案 v1.0（2026-08）
> 视角：游戏策划——先回答"为什么玩家想做这件事"，再回答"怎么做"。

---

## 一、设计愿景

排便目前只是一个"挂机产出器"：拴上去 → 每 2 秒掉一堆大便 → 玩家来捡。
它的玩法深度停留在**资源生产**一层，而且和宝可梦本身毫无关系——任何生物坐在
任何马桶上，产出都一样。

我们的拓展目标是把"排便"从**挂机产出**升级为：

1. **养成的延伸**——排便反映宝可梦的种族、个体、饮食、心情（照顾宝可梦的反馈）；
2. **探索的线索**——排便成为寻找野外宝可梦的追踪机制（新的探索动词）；
3. **建造的目标**——厕所生态成为基地规划的一部分（自动化、美观、收集展示）；
4. **收集的图鉴**——"屎鉴"与宝可梦图鉴形成镜像循环，给收集型玩家一个长线目标。

一句话概括玩家幻想：**"我这个基地是一个运转良好的宝可梦厕所生态系统。"**

---

## 二、核心循环（目标状态）

```
 喂食/照顾宝可梦 ──→ 排便产出（种类/品质 = f(种族, 饮食, 个体, 心情)）
        ↑                          │
        │                          ▼
   亲密度提升 ◄── 铲屎/清理      加工/使用
                                   │
              ┌────────────────────┼─────────────────┐
              ▼                    ▼                 ▼
        肥料→种果树          出售→货币          收集→屎鉴/展示馆
              │                    │                 │
              └────→ 更好的食物/奖励 ─┴───→ 追踪稀有宝可梦
```

三条并行动机线：
- **功利线**（肥料/经济/自动化）——服务生存向玩家；
- **养成线**（亲密度/个体产出）——服务宝可梦训练家向玩家；
- **收集线**（屎鉴/稀有便）——服务图鉴完成向玩家。

---

## 三、点子清单（按系统分组）

### A. 产出差异化：让"是谁在拉"变得重要 ★核心推荐

**A1. 属性系大便**
火属性拉"余烬便"（可当燃料）、电属性拉"静电便"（短时充能红石）、
冰属性拉"冻便"（保鲜）、幽灵属性拉"虚影便"（会定时消失，捡拾有紧张感）、
钢属性拉"金属丸"（可回炉）、恶属性拉"臭臭泥团"（扔出去制造烟幕）……
- 价值：排便结果成为属性知识的具象化，收集驱动强。
- 实现：KubeJS 按物种属性映射产物 id；粒子/音效沿用 PoopSky。
- 成本：低～中（纯数据驱动）。

**A2. 体型决定产量（联动已装的 SizeVariation）**
巨大化宝可梦产量 ×N 但占坑更久；迷你宝可梦产量低但拉得快（"少食多餐"）。
- 价值：让玩家有理由去抓不同体型的同种宝可梦，激活 SizeVariation。
- 成本：低。

**A3. 饮食决定品质**
喂树果后排便品质上升（品质分级：劣质/普通/优质/极品），喂垃圾食物拉"坏便"（只能当肥料，有负面趣味）。
- 价值：把"喂食"和"排便"连成照料循环，玩家会认真规划树果园。
- 实现：给宝可梦记一个"消化缓存"（KubeJS 持久化或 Java NBT），进食后 N 次排便带品质标记。
- 成本：中。

**A4. 个体值彩蛋：金色大便的真正来源**
现在金便靠金马桶。改为：**满 IV 或特定个体（如 6V）的宝可梦在金马桶上才产金便**——
金马桶是"鉴定器"，宝可梦是"矿"。
- 价值：排便系统反向参与孵蛋/刷个体循环（联动 Cobbreeding）。
- 成本：中（需 Java 读个体数据）。

**A5. 闪光专属：彩虹便**
闪光宝可梦小概率拉"彩虹便"，纯收藏向，可放进展示框，是"这只宝可梦是闪的"的实体证明。
- 成本：低。

### B. 探索玩法：野外排便 = 追踪线索 ★差异化最强

**B1. 野宝可梦的粪便痕迹**
野外宝可梦按低频率在脚下留下"新鲜粪便"（带物种信息）。玩家用放大镜/空手检视：
- 新鲜度 → 离开时间（5 分钟内/刚走）；
- 物种 → 附近有什么；
- 状态字段 → 稀有度提示（"金色的！"= 金色个体就在附近）。
- 价值：给"找宝可梦"这个高频行为增加一个侦探式动词，和 Xaero 地图、Cobbledex
  的记录欲完美互补；对 Rad Gyms / 训练家路线周边的探索也有加成。
- 实现建议：痕迹用不可见 marker 实体 + 粒子，检视后生成一次性 tooltip；控制同一区块
  痕迹上限防刷屏。
- 成本：中～高（Java），但**这是全提案里最能立住"排便玩法"独立价值的一条**。

**B2. 追踪任务链（联动 FTB Quests）**
"粪便侦探"章节：跟着痕迹找到指定宝可梦 → 奖励追踪卷轴/图鉴皮肤。
- 成本：低（任务文件）。

### C. 照料与反馈：铲屎官循环

**C1. 厕所卫生度**
厕所被使用后堆积"脏污"（视觉：苍蝇粒子；数值：卫生度下降）。脏马桶上排便品质降低，
宝可梦会拒绝坐。玩家用刷子/冲水（马桶原生）清理。
- 价值：给挂机加上限，逼玩家回归"照料"，同时是天然的产出节流阀（平衡工具）。
- 成本：中。

**C2. 亲密度反馈（联动 Cobblemon 亲密度）**
定期带宝可梦上厕所并"陪蹲"（玩家坐在旁边的马桶上）→ 亲密度小增；
长期不管厕所/被逼拉在野外 → 亲密度微降。
- 价值：把搞笑机制做真心意——"陪蹲"是天然的双人互动瞬间（多人服传播点）。
- 成本：低～中。

**C3. 便秘与消化（轻模拟，可选）**
太久没排便 → 便秘状态（头顶冒泡粒子、移动变慢），喂纤维类树果解决。
反向：泻药类物品 → 立即排便（战术物品，见 D3）。
- 注意：不要做成惩罚性太强的 DEBUFF 系统，控制在"可发现的趣味"级别。

### D. 使用侧：大便的花样消耗

**D1. 肥料树（正经向）**
大便 → 堆肥桶/研磨机 → 属性肥料：火肥催熟辣树果、水肥催熟莓甜甜……
属性树果对应属性肥料的映射，形成"拉→肥→种→喂→拉"闭环。
- 联动：Botany Pots（已装）、Create（研磨）。
- 成本：低（配方数据）。

**D2. 粪便工艺（趣味向）**
金属丸→锻造模板材料；冻便→保鲜盒；静电便→临时充能电池（Create 附加联动）；
臭臭泥团→烟雾弹（战斗外逃逸道具）。金便→金色装饰方块/信标燃料彩蛋。
- 成本：低～中（配方），价值在"群里晒合成表"的传播性。

**D3. 战术消耗品（战斗向，克制投放）**
"投掷大便"：对野生宝可梦使用 → 短时降低其捕捉抵抗但激怒（攻击+）；
对训练家使用 → 好感-1，会被反击（风险自担的搞笑选项）。
- 平衡红线：不影响对战数值强度，只做场外小战术与节目效果。

**D4. 出售与经济（联动 CobbleDollars）**
粪便收购价按"稀缺度"定价：普通便 1 元、属性便 5 元、金便 100 元；
NPC"回收商"（村庄新职业或任务 NPC）每日限购，防止刷钱。
- 成本：低～中；**限购**是防通胀的关键，必须先做。

### E. 自动化与建造：厕所生态工程（联动 Create）

**E1. 自动冲水生产线**
Create 机械手投喂 → 传送带把宝可梦送到厕所 → 自动捡拾器收大便 → 风筝式仓储
（Storage Drawers）。玩家从"捡屎"升级为"设计产线"。
- 价值：整合包的 Create 心智和排便心智第一次交汇，视频传播素材极佳。
- 成本：本模组只需保证"座椅实体可被机械手/部署器交互"，其余交给玩家+Create。

**E2. 公共厕所建筑包（美观向）**
配一个结构模板/FTB Quests 奖励：公共厕所蓝图，含装饰方块清单。给建造党一个展示位。
- 成本：低（资源包/结构文件）。

**E3. 屎鉴展示馆**
结合 A 系产出：展示框墙 + FTB Quests"集齐 18 属性便"终极奖励（称号/披风类）。
- 成本：低。

### F. 收集长线：便便图鉴（"屎鉴"）

**F1. 屎鉴数据页**
每获得一种新大便（按"物种×属性×品质"最小粒度），Cobbledex 弹提示，屎鉴页点亮。
- 目标用户：图鉴完成型玩家（本包已有 CobbleDex 生态）。
- 成本：中～高；可先做简化版（KubeJS 检测首次拾取 → 发自定义进度/任务打勾）。

**F2. 稀有排便事件**
满月夜/雷雨天/特定生物群系，宝可梦排便附带环境彩蛋（月光便、雷雷便）。
- 价值：给时间/天气/空间一个"值得记得"的理由。
- 成本：低（条件表驱动）。

## 四、优先级与路线图

| 里程碑 | 内容 | 理由 |
|---|---|---|
| **v1.1 速赢包**（纯 KubeJS/数据） | A1 属性便、A2 体型产量、D1 肥料配方、D4 限购收购、B2/E3 任务章节 | 一两周内让排便"有的选、有的用、有的卖"，先验证玩家是否在意 |
| **v1.2 照料包** | A3 饮食品质、C1 卫生度、C2 亲密度、B1 简化版（无 Java，改为任务提示） | 建立"照料"循环与产出节流 |
| **v2.0 探索包**（Java） | B1 粪便追踪完整版、A4 金便鉴定、F1 屎鉴 | 立住差异化卖点 |
| **长期** | E1 自动化细节打磨、F2 稀有事件、赛季活动（捡屎大赛） | 运营型内容 |

依赖关系提醒：A4、C2、B1 需要 Java 侧读 Cobblemon 数据（个体/亲密度/物种属性），
建议沉淀一个 `PoketoiletAPI`（读取宝可梦上下文 → 返回产出修饰表），让 KubeJS 只做
"填表"，Java 只做"取数"，后续所有拓展都在数据层完成。

## 五、平衡护栏（策划自查清单）

1. **产出节流阀优先于产出倍率**：加产量之前先加卫生度/限购/消化缓存等"刹车"，
   防止大便通胀击穿 CobbleDollars 经济。
2. **排便不绑架战斗**：所有战斗向产物（D3）只做场外效果，不进数值系统。
3. **搞笑但不恶心**：视觉走 PoopSky 现有的卡通化风格；避免真人向的污秽表现，
   粒子和音效保持"麦块式无厘头"。
4. **尊重动物只是一种设定**：宝可梦排便应是"自愿的、有奖励的"（陪蹲加好感），
   避免任何"强迫/虐待"观感的机制文案。
5. **每个新物品都要有去处**：新增一种大便，必须同时回答"它有什么独占用途"，
   否则就是背包垃圾。

---

## 六、最先做的三件事

1. **属性便映射表（A1）+ 肥料配方（D1）**——成本最低，立刻让排便系统"看起来活了"；
2. **回收商限购（D4）**——先装刹车再踩油门；
3. **"粪便侦探"任务章（B2）**——用 FTB Quests 讲清楚新机制，顺便埋 B1 的期待。
